# 읍면동 주민센터 기준 좌표

수동 지역 선택의 거리 기준은 **해당 읍면동의 주민센터(행정복지센터·읍면사무소) 실제 위치**다.
등록 주소의 임의 지점, 예보 지점, 행정구역 중앙점, 업체 평균점과 다른 동의 주민센터를 사용하지 않는다.

## 현재 반영 범위

2026-11-03 수집·검토한 공식 자료에서 등록 읍면동 3,554개 중 **3,194개**를 연결했다.
**360개는 미확인**이며 전국의 모든 주민센터 좌표를 확보한 상태가 아니다. 이 중 62개는
동일 기준일의 좌표 충돌 또는 다른 주소들이 동일 좌표를 공유하는 문제로 제외했다.
미확인 지역은 지역 API에서 좌표를 null로 반환하며 업체 위치 검색은 422다.
자동·수동 모두 구·시 경계 없이 기본 5km, 최대 20km 반경을 검색한다.

- `community_centers_20261103.csv`: 실제 반영한 주민센터 이름·주소·WGS84 위경도·출처·확인일
- `community_centers_pending_20261103.csv`: 등록 동 중 확인이 필요한 전체 목록과 사유
- `community_centers_20261103.conflicts.json`: 임의 선택하지 않은 충돌 자료
- `community_centers_20261103.sources.json`: 실제 채택한 공식 원본의 URL·SHA-256·행 수
- `community_centers_ddm_20261103.csv`: 동대문구청 공식 지도에서 추출한 주민센터 목록
- `community_centers_juso*_20261103.csv`: 주소정보누리집에서 건물명으로 확인한 주민센터·읍면사무소
- `community_centers_address_points_20261103.csv`와 `.audit.json`: 공식 기관 주소와 정확히 같은 건물의 좌표 및 대조 기록
- `community_centers_20261103.address_requests.csv`: 공식 기관 주소는 있으나 좌표 확인이 더 필요한 목록

출처 식별자의 날짜는 원본 자료의 기준일(확인할 수 없는 경우 UNDATED) 또는 공식 지도 확인일이다.
CSV의 `verified_at`은 공식 자료를 수집·대조한 날이며 현장 방문일이 아니다.
`center_source_code`에는 전체 지역 계층의 SHA-256 앞 30자라는 내부 행 식별자를 저장한다.
이 값을 타 기관의 행정코드로 해석하면 안 된다.

## 공식 자료와 선정 규칙

- [동대문구청 동주민센터 공식 지도](https://www.ddm.go.kr/www/contents.do?key=293)
- [마포구 동주민센터 공간정보](https://www.mapo.go.kr/site/main/openData/view?dataId=199)
- [주소정보누리집 공식 지도](https://www.juso.go.kr/map/totalMapView)
- 공공데이터포털의 지자체 주민센터 위치 파일: 실제 사용한 파일은 sources.json 참고
- [전국공공시설개방정보표준데이터](https://www.data.go.kr/data/15013117/standard.do)
- [전국전동휠체어급속충전기표준데이터](https://www.data.go.kr/data/15034533/standard.do)

표준 시설 자료는 시설이 해당 주민센터 **건물**로 명시된 행만 사용한다. 인근 공원, 옆 시설,
관할기관 이름만 같은 시설은 제외한다. 시도·시군구·읍면동 전체 계층과 주민센터 이름을
연결하며 법정동명이나 숫자가 다른 동을 임의로 연결하지 않는다. 자료에서 확인한 도로명주소가
등록된 시군구 범위와 대응하는지도 확인한다. 기존 앱 지역 동기화와 동일한 도 명칭 변경을
반영하며 주소 자체는 원문을 보존한다.

주소정보누리집에서는 실제 건물명이 주민센터·행정복지센터·읍면사무소인 결과만 채택한다.
창고·주차장·인근 아파트 등은 제외한다. 공식 기관 목록에 주소만 있는 경우에는 그 도로명주소와
정확히 같은 활성 건물만 연결하며 인접 주소로 대체하지 않는다. 공식 지도에서 사용하는
EPSG:5179 좌표를 WGS84 위경도로 변환하며 투영 변환은 별도 오프라인 테스트로 검증한다.

같은 동의 여러 자료는 원본 기준일이 최신인 행을 우선한다. 같은 기준일에는 지자체 공식 지도와
공식 기관 주소를 정확히 대조한 건물을 우선하고, 다음으로 기관 목록·주소정보누리집의 건물명,
마지막으로 시설 내부 설비 자료를 사용한다. 동일 우선순위에서 50m 넘게 충돌하는 좌표는
평균을 내거나 하나를 임의 선택하지 않고 확인 대기로 분류한다. 다른 건물 주소가 동일한
좌표를 공유하는 경우도 공통 중앙점일 수 있으므로 제외한다. 좌표 검사는 한국의 위경도
범위, 유한 수, 정밀도 일곱 자리에 적용한다.

송파구 파일 15116616의 위도·경도 열 표기가 뒤바뀐 경우는 해당 원본에 한해서 순서를
바로잡는다. 일반 입력에서 자동으로 좌표를 바꿔 끼우지 않는다.

휘경1동은 구청 공식 지도에 표시된 `37.59303, 127.06576`(외대역동로6길 3),
휘경2동은 `37.59021, 127.06866`(한천로 329)을 사용한다.

## 반영과 검증

`config/region_centers.php`에서 고정된 파일과 해시를 확인한 뒤 로컬 유지보수 명령으로 반영한다.
외부 HTTP 수집, Python 실행이나 DB 변경을 일반 API 요청 안에서 수행하지 않는다.

```sh
composer db:import:region-centers:plan
composer db:import:region-centers
python3 -B tests/community_center_reference.py
python3 -B tests/community_center_projection.py
composer test:database
```

적용은 트랜잭션으로 수행한다. 이번 참조 자료에서 확인되지 않은 기존 좌표는 출처와 무관하게
제거하고 확인한 주민센터 좌표를 반영한다. 이전에 연결했더라도 새 검토에서 충돌하면 제거한다.
기존 지역 ID, 코드, 부모 관계와 업체 연결은 유지한다. 빈 자료나 등록 동이 하나도 대응하지 않는
자료는 적용하지 않는다. 수입을 반복해도 같은 좌표와 출처를 유지한다.

`bin/build-community-centers-reference.py`는 다운로드한 공식 CSV·JSON과 공개 지역 목록으로
참조 CSV를 재구성하는 로컬 도구다. 사용법은 파일 첫 부분에 있다. 순서는 지역 JSON,
공식 CSV 디렉터리(manifest.json 포함), 동대문구 원본 CSV, 공공시설 표준 JSON,
충전기 표준 JSON, 출력 CSV와 선택적인 주소정보누리집 CSV들이다.
공식 CSV manifest는 id, title, filename, source_url, download를
담는다. 파일은 sources.json의 공식 URL에서 다시 확보한다. API 키, 유료 지도 호출, 추가
패키지와 운영 서버의 Python은 필요하지 않다.

`bin/collect-juso-community-centers.py CACHE_DIRECTORY OUTPUT_CSV [KEYWORD]`는 공식 지도와
동일한 공개 읽기 전용 검색으로 `주민센터`(기본값), `행정복지센터`, `동사무소`, `면사무소`,
`읍사무소`를 수집하는 로컬 도구다. 이번 대조에서 행정복지센터 검색 결과는 주민센터 검색과
동일했고 동사무소 검색도 신규 검증 지점을 추가하지 못해 중복 스냅샷은 보관하지 않았다.
페이지당 10건, 최대 10,000건, 동시 요청 3개로 제한하고 원본 응답을 캐시에 보관해 재개한다.
`bin/geocode-community-center-addresses.py OFFICIAL_ADDRESS_CSV CACHE_DIRECTORY OUTPUT_CSV`는
누락 좌표가 있는 공식 기관 주소를 같은 지도에서 정확한 건물 주소로 대조한다. 일반 API 요청이나
운영 서버에서는 수집·주소 검색을 수행하지 않는다.

과거의 `region_centers_kma_20260701.csv`와 변환 스크립트는 이력 자료다. 현재 설정·수입과
거리 계산에는 사용하지 않는다. API도 OFFICE- 출처가 아닌 좌표를 주민센터 위치로 노출하지 않는다.
